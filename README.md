# Karate-club-Assignment

DSC-212 : Spectral Modularity Partitioning on Zachary's Karate Club

Note : I used AI assistance to help develop, debug and organise the Python code used in this assignment. The implementation involved libraries such as NumPy, NetworkX, Matplotlib and Pandas. I independently studied and worked through the mathematical concepts behind the project, including the modularity matrix, configuration null model, Rayleigh–Ritz theorem, spectral partitioning, Newman's generalised modularity matrix for subgroups, and the eigenvalue-based stopping condition. I also focused on understanding the numerical results, comparing corrected and uncorrected partitioning approaches, and analysing the changes in node centrality across successive partitions. AI assistance was used as a supporting tool during implementation and refinement, while the mathematical understanding and interpretation of the results were developed through my own study.
